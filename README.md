# Alien Invasion

Alien Invasion is a simple game built using Python and Pygame. The objective of the game is to create an interactive environment where players can defend against an alien invasion.

## Features

- A game window with a resolution of 800x600 pixels.
- Basic event handling for quitting the game.

## Prerequisites

To run this game, you need to have the following installed:

- Python 3.x
- Pygame library

## Installation

1. Clone this repository or download the source code.
2. Install the Pygame library by running:
   ```bash
   pip install pygame
   ```
